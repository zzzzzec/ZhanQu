# 0.1.1：悬浮窗口生命周期与安全边界

历史变更说明，不代表当前源码的真机验收记录。

- 自身悬浮窗口使用独立随机标识和原生窗口 ID。替换窗口期间保留仍可验证的退役窗口登记；ID 或标识不匹配时不豁免。
- 只对已确认 SystemUI、非活动且非焦点、精确区域均处于系统栏边缘的窗口使用分离区域。未知浮窗、键盘和弹窗仍保守检查。
- 截图、滑动和节点动作使用系统栏及刘海安全内容区域；动作前隐藏自身面板并重新验证。
- 截图前后指纹包含实际采用的区域；错误不输出页面文字或账号信息。
- 数据结构和数据库迁移不变。

回归覆盖自身与外部窗口、空根窗口、ID 复用、系统栏分离区域、通知面板、键盘和下层窗口。纯 JVM 策略回归不代替 Android 截图与手势实测。
