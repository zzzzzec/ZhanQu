# 0.2.3：收起后仍停靠屏幕边缘

- 版本：0.2.3 / versionCode 8。
- 修复：展开面板收起时，小入口沿用面板左坐标而落在屏幕中间。现在独立保存左/右停靠边，依据新宽度重新计算坐标，而不是仅限制旧坐标不越界。
- 展开/收起、运行状态高度变化、诊断内容变化和可用屏幕区域变化均复用现有窗口；左右锚点不因变窄或旋转而重新推断。
- 拖动过程中保留当前触摸视图与坐标，不抢回屏幕边缘；需要的界面重绘延迟到松手/取消后，再选择最近边缘。
- 仍保留屏幕安全边距和纵向边界约束。没有改动数据存储、采集、侧栏遮挡判定、安全点击或授权流程。

测试范围见 TEST_REPORT.md。框架回归不能替代三星目标机实测；真实旋转、拖动手感、覆盖安装和笔记保留仍需设备验证。请勿为了更新主动卸载现有预览版。
