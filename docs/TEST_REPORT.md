## Android界面与采集流程

独立调试包的四项界面仪器测试通过，覆盖首次引导与帮助、编辑保存及重启、未保存修改、导出菜单与系统文件选择器返回。测试使用随机ID的合成笔记，完成后只删除自己的样本。

采集流程另行检查自动识别、图文顺序、当前回答边界、主评论与子评论、暂停、主动保存结束、悬浮入口和JSON实际写出回读。验证只覆盖已执行的页面与操作，不代表所有应用版本或全部远端评论均可采集；页面显示数量、实际已采数量与结束标记分别保存。

原始页面、账号信息、设备标识、截图、数据库、导出文件和详细诊断留在本地忽略目录。公开报告不附这些内容或本地证据路径。
