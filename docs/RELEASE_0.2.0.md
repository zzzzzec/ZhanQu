# 0.2.0：界面与悬浮控制重构

版本 0.2.0 / versionCode 5。本版不改变采集规则、数据库结构或网络权限。

## 主界面

- 浅米色背景与绿色主题，卡片化区分采集准备、状态和统计。
- 本地笔记搜索与空状态，保留编辑、复制、分享及三种导出。
- 离开未保存编辑时提供放弃确认。

## 悬浮控制

- 折叠与展开使用同一无障碍窗口，保留原有窗口身份登记。
- 紧凑模式可暂停 / 继续；展开详情可滚动，操作区独立。
- 标题区可拖动，拖动时暂停采集；松手吸边，并约束到安全视口。
- 开始后折叠；停止保存期间禁用重复控制。
- 截图和手势期间隐藏自身面板，原有页面及窗口安全校验保留。

新增 OverlayPlacement 与 CaptureControlPolicy 的纯 JVM 回归，分别覆盖视口几何及操作状态。编译、测试执行情况见 [TEST_REPORT.md](TEST_REPORT.md)。这些测试不证明真机触摸、旋转、字体缩放、无障碍读屏或不同 OEM 窗口行为，仍需按 [TEST_PLAN.md](TEST_PLAN.md) 验证。

公开源码不包含私人快照、原图、笔记、历史日志、签名私钥或本地配置。许可证未变更。

## 独立预览构建

构建参数 `-PzhanquPreview=true` 使用 `dev.zhanqu.app.preview` 包名与“粘取预览”名称，可与默认应用并存。笔记存储彼此独立，不自动迁移原版数据；请只启用一个无障碍采集服务。默认构建仍使用 `dev.zhanqu.app`。任何覆盖更新仍须匹配旧签名，不能通过升级版本号绕过签名校验。
