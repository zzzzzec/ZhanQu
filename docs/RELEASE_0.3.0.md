# 0.3.0 · 交互打磨

这次聚焦日常使用：悬浮入口更轻，菜单主次更明确，主页与笔记编辑各司其职。

## 设计依据

参考成熟工具的交互模式，不复制品牌图形：

- [Apple AssistiveTouch](https://support.apple.com/en-us/111794)：可移动的边缘入口与按需展开菜单。
- [Samsung Edge](https://www.samsung.com/us/support/answer/ANS10002367/)：侧边入口减少常驻遮挡。
- [TextSniper](https://textsniper.app/)：启动、执行、得到可用文字的短路径。
- [Universal Copy](https://play.google.com/store/apps/details?id=com.camel.corp.universalcopy)：围绕文字的选择、累积和使用组织操作。

上述来源只说明参考模式；不代表粘取实现了这些工具的全部能力。

## 本轮变化

- 56dp 入口降低待机背景存在感，使用明确的采集图形；触控区不缩小。
- 216dp 菜单为图文、评论、回复增加短标签，突出单个提取动作；运行时显示暂停、继续和完成。
- 首页改为笔记列表与采集入口，帮助、权限和清空操作收进菜单；无关状态不常驻。
- 笔记使用独立编辑页，复制、分享和导出集中呈现；返回时保留未保存确认。
- 小高度、大字体或键盘场景下编辑页可滚动；采集回调不再主动打开笔记，也不会覆盖正在编辑的内容。
- 数据、截图与遮挡检查保持原有策略，没有为简化界面而移除保护。

## 数据与兼容

数据库和采集引擎保持不变。预览包沿用0.2.1起的包名和固定签名，versionCode从8递增到9。已有边缘锚点与窄侧栏安全点击逻辑保留。

最终验证结果见[测试报告](TEST_REPORT.md)。

## 保留的验收边界

框架渲染与合成测试不替代三星实机的触摸、截图、系统文件选择器与覆盖安装验收。当前实现不接管系统返回键关闭悬浮窗，也没有新增全屏遮罩来拦截窗外触摸。
