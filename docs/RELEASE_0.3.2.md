# 0.3.2 · 非聚焦浮层不再中断

版本号 0.3.2，versionCode 11。

- 取消侧栏、悬浮窗等非聚焦窗口的几何遮挡拦截，适用于图文截图、节点操作、滑动与页面快照。
- 截图前后仅比较目标窗口身份和坐标，不再比较无关窗口的集合或几何变化。快照和采集事件检查忽略已确认非聚焦的独立浮窗；真实前台切换、目标页面切换仍会中止。无法确认身份的同应用页面切换事件仍保守中止。
- 评论作者、时间、地区及点赞等字段按每条评论单独选择备用 ID，避免同屏其他评论命中首选 ID 时造成字段遗漏。
- 保留密码页、锁屏、前台焦点与 Android 系统安全截图限制，不绕过 FLAG_SECURE。
- Android 11–13 的屏幕截图可能包含可见浮层；Android 14+ 继续使用目标窗口截图。

合成测试覆盖侧栏、中央浮窗、窗口增减/移动、真实焦点变化及切走再返回。最终构建与回归结果见 TEST_REPORT.md；合成测试不代表具体手机的真机验收。

评论计数及层级问题仍需结合实际页面结构核实，不能仅凭取消遮挡拦截认定全部修复。
