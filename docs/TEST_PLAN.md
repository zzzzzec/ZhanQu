# 最短实机验证清单

## 先验证安装和权限
- 在目标 Android 11+ 设备安装 APK，首次首页能打开；系统无障碍设置能找到“粘取页面采集”。
- 先不启用服务：首页不崩溃；拒绝或撤销服务权限后保持可打开。
- 启用后在小红书非敏感笔记点击悬浮入口，再明确开始；首页同意前不能开始。

## 图文与离线OCR
- 从1/7和2/7分别开始，逐页核对1…7。应只得到7张顺序正确且不同的图页；检查页号、重复图错误和OCR原文。
- 首次安装后关闭网络再OCR一页，确认无需下载模型。联网与断网测试只影响图片是否已由来源App加载。
- 手动切换App、返回列表、打开另一篇笔记、锁屏、旋转时必须暂停/停止；恢复前重新验证页面。
- 截图系统保护/限频、慢加载、滑动不动时应给出错误并保留部分文字。
- 开始后暂停/停止，回笔记库，强杀重启仍能看已写入checkpoint；绝不自动后台继续。

## 评论与导出
- 评论模式必须从已识别图文笔记页开始；若已深滚评论导致图文锚点缺失，先返回图文顶部再开始。
- 保留显示总量与提取总量分离。楼中楼展开前后检查新增、父子关系和未确认父级。
- 同文不同作者/时间不可错误去重；连续无新增只能“疑似结束”。
- 编辑并保存后继续采集、重新打开App，人工校正不被checkpoint覆盖。
- Markdown/TXT/JSON经系统文件选择器导出；复制全文/分享内容真实且页序正确。
- 停止后清空本地记录，重启App不应重新出现刚清空记录。

## 建议反馈
提供App版本、Android版本、操作步骤、错误提示和是否到达某页。日志只需异常类型与步骤，不要发送账号、敏感页面原文、截图或凭证。默认日志无正文。

## 待测指标
7页成功率、30张中文样本CER/漏行/段落顺序、每页耗时、内存峰值、真实评论覆盖率均待实测；单页快照解析或JVM状态机测试不代替端到端手机验收。

## 0.2.0 界面与悬浮窗

- 在紧凑与展开模式检查开始、暂停、继续、停止、保存中、已完成的状态及按钮可用性。
- 拖动标题区，确认正在采集的任务暂停；释放后吸边且按钮没有落到系统栏或屏幕外。
- 旋转屏幕、放大系统字体并在小屏设备展开详情，确认内容可滚动，操作仍可达。
- 采集截图不应包含自身控制面板；展开 / 折叠不应把自身窗口误判成外部遮挡。
- 连续点击停止不能重复触发；停止保存后已完成结果仍可打开。
- 编辑笔记后离开，分别验证保留编辑和确认放弃路径；不要用私人内容录制反馈。

## 独立预览安装

- 预览包与原版应并存；原版笔记保持不变，预览笔记库初始独立。
- 系统设置应能区分“粘取页面采集”和“粘取预览页面采集”；一次只启用一个。
- 预览包不自动迁移、覆盖或删除原版数据；不要通过卸载原版解决签名不匹配。
