# 0.2.2 开发测试版

## 本次修复

评论入口或楼中楼标签可能属于横跨页面的可点击行。0.2.1 按整行检查遮挡时，窄侧栏即使远离标签，也会使点击停止。0.2.2 保留原检查，并仅在非聚焦、已知来源的窄侧栏造成整行阻挡时，重新核对页面与节点，再尝试标签中心的实际点击。

- 点击区域必须完整位于可见标签、目标节点和屏幕内容区内，并保留安全边距。
- 检查所有相关窗口，不按三星或任何包名设置白名单。
- 未知窗口、中央遮挡、焦点变化、非默认显示屏和节点身份或位置变化仍拒绝操作。
- 手势拒绝、取消或超时不计为成功，不自动重试不确定动作；完成后仍检查页面内容是否变化。
- 已派发的在途手势不能保证因暂停或协程取消而撤回。
