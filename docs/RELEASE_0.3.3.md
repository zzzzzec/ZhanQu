# 0.3.3 · 评论结构与图片完整性

版本号 0.3.3，versionCode 12。

- 无障碍服务请求完整结构节点，保留评论主层与回复层的容器信息。
- 识别小红书评论列表中带横线、空白等装饰字符的到底标记。
- 图片截图前后比较原生布局尺寸和实际可见区域，避免把滚动后仅露出的局部图像记为完整页；无法确认边界时保留不完整状态并提示返回顶部。
- 增加独立 `dev.zhanqu.app.devtest` 构建、四项界面自动回归和独立页面测试驱动；测试生成的内容不进入产品 APK。
- 后续平台按应用与场景编写专门代码，不扩展为低代码流程配置平台。

小红书已在特定版本与真机样本上验证页码、评论结构及暂停恢复；OCR 错字、多栏顺序和折叠评论全文仍有已知问题。官方模拟器中的小红书与知乎启动验证未通过，未新增知乎提取支持。具体测试边界见 [TEST_REPORT.md](TEST_REPORT.md)。

预览包、默认包、调试包分别使用独立数据。升级时核对包名与签名；不得通过卸载解决签名冲突，以免丢失笔记。
