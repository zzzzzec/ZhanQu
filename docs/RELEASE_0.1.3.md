# 0.1.3：评论入口与 OCR 排版

历史功能变更说明。评论成功率和字符识别率均需真机测量，不能由策略或几何单元测试推断。

## 评论入口

增加有序入口候选 `nested_header`、`noteContentLayout` 及已知 `noteDetailRoot` 下的 `noteContent`。父区域缺失时，仅在图文识别锚点成立后尝试轮播内容区域中的受检纵向滑动。只有规则声明的 `noteCommentLayout` 评论按钮可以作为点击入口，不点击输入框、点赞或收藏。

入口最多 10 次操作，连续 3 次无有效变化时停止。进入前后检查包名、Activity、窗口、笔记身份、锁屏及弹窗；已加载但屏外的列表不算到达可见评论区。

## OCR 与数据

- 分别保留原始 ML Kit 文字和排版结果。JSON schemaVersion 2 增加输入宽高、rawText、layoutVersion 和排版略去项。
- 根据坐标组织同行、几何换行及分栏；小字号嵌图文字作为独立区域保留。
- 仅略去严格匹配页码且位于角落的孤立计数，以及符合细长几何的装饰竖线。原文和坐标仍保留。
- 坐标缺失或异常时退回原始文字，不猜补跨页句子、不转换繁简、不猜改错字。
- 截图保留实际分辨率，不进行 JPEG 二次压缩或无依据放大。
- 旧页模型缺少 rawText 时回退到原 text；数据库结构不变，保留编辑内容。

## 单张图片对比

系统文件选择器支持主动选择一张图片，在设备本地识别并导出原始 / 排版 JSON。单图上限 2,000 万像素，超限拒绝，不静默降采样；不请求广泛存储或网络权限。

这些改变改善的是排版与可核对性，不构成已提高字符识别率的结论。实测应记录 CER、漏行、阅读顺序、耗时及内存，并使用获得授权的评测内容。
