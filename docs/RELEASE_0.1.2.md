# 0.1.2：目标窗口截图与实际手势路径

历史变更说明，不包含个人设备、页面或诊断样本信息。

本版区分整屏截图与 Android 14+ 目标窗口截图的遮挡策略：

- Android 14+ 目标窗口截图：仅允许非活动、非焦点的 SYSTEM / OTHER 窗口位于所采区域外围；中央 80% 区域被遮挡则停止。不把未知窗口当成可信窗口，不裁掉边缘冒充完整截图。
- Android 11–13 整屏截图：整块 OCR 区域仍须无遮挡。
- 外部无障碍浮层、键盘和应用弹窗仍受限；非自身窗口抢占活动或焦点状态时停止。锁屏、密码区、系统拒绝和限频行为不变。
- 手势使用同一 SwipePlan 计算实际路径与 12dp 安全边距。路径与未知浮窗相交时不执行。
- 原生列表容器被遮挡时不执行其节点动作，只尝试既有的受检路径回退。
- 诊断采用类型、窗口 ID、活动/焦点状态、包名、区域和标题摘要，不输出原始窗口标题、正文或截图。摘要并非匿名化保证，公开反馈仍须审查。

这些策略需要在目标设备验证。单元测试不证明系统窗口行为或实机成功率。版本间更新需匹配签名；卸载前请导出数据。
