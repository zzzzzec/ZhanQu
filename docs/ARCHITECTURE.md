# 实现边界

- `core/`：Android 无关的不可变 UiSnapshot/UiNode/UiBounds、受限 JSON 规则、候选定位器、页码与轮播状态校验、评论解析与启发式去重、GKD ZIP/JSON 导入。可运行 JVM 回归测试。
- `capture/`：AccessibilityService 与小型操作悬浮层、每次动作新读节点树、截图窗口坐标转换、有限手势、可暂停协程工作流、容量1的图像队列、ML Kit bundled OCR。原生节点引用不跨动作缓存。
- `data/`：Room 内部库，原始结构化 JSON 与用户校正文本同时保存。checkpoint 不覆盖已明确保存的人工校正。
- `export/`：纯文本/Markdown/JSON，逐页来源、评论父级、完整性与错误。只通过 UI 明确复制、分享或 SAF 导出。
- `MainActivity`：披露与授权引导、状态、笔记搜索、预览编辑、导出。

JSON DSL 接受已定义字段，不执行脚本、Shell、网络请求或跨包动作。每个 profile 具有目标包、识别锚点、有限策略与数量/超时上限。新增可复用相同轮播/评论策略的适配器无需重写工作流；未知策略被拒绝。当前安装包只暴露内置小红书入口，第三方 profile 导入编辑器属于后续界面工作。

## 诚实降级

未知页码不猜测总量；当前实现要求可验证的页码才自动翻页。截图完全重复、跳页、总数变化、OCR空文本均保留不完整状态。列表不再变化仅记“疑似到底”，不等于确认全部评论。无稳定源ID时评论指纹不能绝对识别所有重复/同文情况。屏外节点已有文本可读取，但动作/截图仅限可见有效区域。

每个任务保留已完成页和错误。恢复仅在同一笔记窗口重新验证后继续；进程被杀后保留 Room checkpoint，但不自动恢复后台手势。截图未写入磁盘，不提供原图永久留存功能。

## 保存与中断保障
保存由进程级串行写入器完成，不随无障碍服务协程一起取消；每个笔记仅保留最新待写checkpoint。Room事务保留已保存的人工校正，编辑只更新编辑列而不回滚采集结构。清空操作写入时间标记，旧会话排队结果不能复活已清空记录。进程被系统强杀仍可能丢失最后一个尚未落盘checkpoint，因此重要结果请导出。

版本2数据库提供1→2非破坏迁移；本次未在手机上执行迁移测试。页面没有稳定源笔记ID时，同窗口静默替换且身份字段缺失仍无法绝对识别；现有防护为初始身份字段、Activity/窗口事件、页码、尺寸和页面锚点验证，不声称适配所有未报告的界面变化。
