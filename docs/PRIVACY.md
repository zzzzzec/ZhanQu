# 隐私与权限
粘取是用户主动启动的个人内容整理工具，不宣称为残障人士辅助工具。无障碍权限用于读取当前选择页面节点、截图和有界手势。首次首页显示用途披露，接受后由用户自己在 Android 设置启用。可以随时关闭服务。

- 不声明 INTERNET、联系人、短信、广泛存储、悬浮窗系统权限；ML Kit Chinese 模型随 APK 捆绑，正文无需上传。
- 只在悬浮操作面板点击开始后启动采集；目标包名与页面锚点不符、锁屏、窗口/方向变化时暂停。
- 密码节点拒绝读取；系统 secure-window 截图拒绝不绕过。系统截图限频仅有限重试。
- 截图只存在内存中的有界队列，不写入相册或私有缓存；处理完释放。应用被系统终止时内存由系统回收。
- Room 保存在应用内部目录，禁用 Android 自动备份。导出使用系统文档选择器，分享由用户明确点击。
- 调试日志不记录采集原文。源码包不包含用户原始 GKD ZIP、JSON 或 PNG。
- 对无障碍服务的触摸事件通知依设备而异，请保持手机不操作；出现异常可手动暂停/停止。
- 仅处理有权访问且用户主动选择的页面；不得绕过第三方访问控制、验证码、付费内容或安全设置。

## 分享与反馈的边界

无网络权限不意味着导出内容已匿名化。OCR 原文、作者、评论、时间和人工编辑可能保存在内部数据库及导出文件中；系统分享、剪贴板和你选定的文件提供方会接收你明确分享的内容。请在操作前检查接收方和内容，不要公开未经脱敏的笔记、截图、JSON 或诊断信息。

清空内部笔记不会删除已导出到其他位置的文件。卸载会删除应用内部数据；请自行管理和删除外部副本。公开仓库使用合成样本，不应添加私人采集内容。
